## How I approach projects
I start small: ship a minimal working example, then improve it. Typical steps:
1. Build a clear, working prototype.
2. Separate concerns (routes, services, data access).
3. Add README and scripts so others can run the project.
4. Iterate: add tests, refactor, and improve developer experience when it makes sense.
